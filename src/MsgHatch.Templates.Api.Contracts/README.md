# MsgHatch.Templates.Api.Contracts

The HTTP contracts of the template management API of [MsgHatch](https://github.com/biliktamas79/MsgHatch): the request and response bodies, their mappings to the types of `MsgHatch.Templates`, and their source-generated JSON context.

The endpoints of `MsgHatch.Templates.AspNetCore` and the client of `MsgHatch.Templates.Api.Client` share these bodies. The package has no HTTP concern, no setup method, and no options.

## Install

```shell
dotnet add package MsgHatch.Templates.Api.Contracts
```
